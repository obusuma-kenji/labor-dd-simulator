# 🎮 事業承継DDシミュレーター（完全版・6ステージ）

**労務デューデリジェンス（DD）を体験できる本格シミュレーションゲーム**

事業承継における労務リスクを発見し、AIコンサルタントと対話しながら学べる教育ツールです。

## ✨ 特徴

### 🏢 6つの企業シナリオ

| ステージ | 業種 | 従業員 | 年商 | 難易度 | 主なリスク |
|---------|------|--------|------|--------|-----------|
| **Stage 1** | 製造業 | 120名 | 32億円 | ★★☆☆☆ | 未払残業代、36協定違反、無期転換権 |
| **Stage 2** | 飲食業 | 65名 | 5.8億円 | ★★★☆☆ | 社会保険未加入、同一労働同一賃金 |
| **Stage 3** | 介護事業 | 65名 | 4.2億円 | ★★★★☆ | 処遇改善加算返還、夜勤管理、無資格者配置 |
| **Stage 4** | IT企業 | 45名 | 6.8億円 | ★★★★★ | 裁量労働制違反、固定残業代、偽装請負 |
| **Stage 5** | 建設業 | 25名 | 8.5億円 | ★★★★★ | 一人親方問題、元請責任、労災隠し |
| **Stage 6** | 物流業 | 65名 | 12億円 | ★★★★★ | 2024年問題、改善基準告示違反、点呼不備 |

### 🤖 AIコンサルタント機能
- **Gemini 2.0 Flash**搭載
- カード選択理由を入力 → AIが評価・アドバイス
- 適切度スコア、強み、注意点、代替案を提示

### 📊 自社診断機能
- ゲーム終了後、自社の労務リスクを診断
- 業種別チェックリスト（8項目×6業種）
- リスクスコア算出（0-100点）
- 無料相談の申し込みフォーム（リード獲得）

## 📊 各ステージの詳細

### Stage 1: サカエ精工（製造業）
**企業概要**: 自動車部品プレス加工の地方製造業  
**主なリスク**:
- 未払残業代（2,800万円）
- 36協定違反（2,200万円）
- 無期転換権の発生（1,500万円）
- 技能承継の遅れ（1,000万円）

### Stage 2: 割烹すずかぜ（飲食業）
**企業概要**: 老舗割烹料理店  
**主なリスク**:
- 未払残業代（3,200万円）
- パート社会保険未加入（2,500万円）
- 同一労働同一賃金（1,800万円）
- ハラスメント（1,200万円）

### Stage 3: ケアサポートひまわり（介護事業）
**企業概要**: 通所介護・訪問介護事業者  
**主なリスク**:
- 処遇改善加算返還（1,500万円）
- 夜勤残業未払い（1,200万円）
- 無資格者配置（800万円）
- メンタルヘルス不備（600万円）

### Stage 4: テックソリューションズ（IT企業）
**企業概要**: システム開発・SaaS事業者  
**主なリスク**:
- 裁量労働制違反（3,000万円）
- 固定残業代不適切運用（2,500万円）
- フリーランス偽装請負（1,800万円）
- 36協定違反（1,000万円）

### Stage 5: 大成建設工業（建設業）
**企業概要**: 地域密着型総合建設会社  
**主なリスク**:
- 一人親方の偽装請負（4,500万円）
- 社会保険未加入問題（2,800万円）
- 長時間労働・36協定違反（1,800万円）
- 労災隠し（1,200万円）
- 外国人技能実習生違反（800万円）

### Stage 6: 関東ロジスティクス（物流業）✨ NEW!
**企業概要**: 一般貨物運送・倉庫業  
**主なリスク**:
- **2024年問題**（時間外労働上限超過）（5,000万円）
- **改善基準告示違反**（拘束時間・休息時間）（3,500万円）
- **点呼記録の不備**（2,200万円）
- 運行管理者の未選任（1,800万円）
- 傭車の偽装請負（1,500万円）

**2024年問題とは？**  
2024年4月から、自動車運転業務の時間外労働上限規制（年960時間）が適用されました。これにより、多くの運送会社が事業継続の危機に直面しています。このシナリオでは、2024年問題への対応不備がどれほど深刻なリスクになるかを体験できます。
